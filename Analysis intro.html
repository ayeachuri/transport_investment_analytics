Transport Data Preparation for OECD Analysis Dashboard

Overview

This notebook focuses on preparing OECD Transport Performance Indicators data for visualization in a Streamlit dashboard. The primary purpose is to transform raw transportation metrics from various countries into clean, analysis-ready datasets that can be easily loaded into interactive visualizations.

Data Source

The primary data is from the OECD Data Explorer, Transport Performance Indicators, supplemented with economic indicators for contextual analysis.

The dataset includes more than 90 performance indicators related to transport across 70 countries.

The indicators cover seven themes:

infrastructure equipment activity safety traffic economic and social environment

Key Transformation Steps

  1. 1. Data Cleaning: Handle missing values, standardize formats, merge related columns
  2. 2. Filtering: Select high-information countries (43 countries with at least 30 metrics each)
  3. 3. Time Series Compression: Represent yearly data with linear regression parameters (predicted 2000 value + slope)
  4. 4. Dimension Handling: Create specialized formats for all analyses (aggregated, wide, and semi-wide)
  5. 5. Metadata Creation: Document measures, units, and categories for dashboard integration
